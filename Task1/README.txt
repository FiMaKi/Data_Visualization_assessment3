# Task 1: CoffeeAndCode Static Visualisation

This project creates a static heatmap showing how average daily coding hours vary by age group and ability to code without coffee.

## Required tools

- Python 3
- pandas
- numpy
- matplotlib

## Files

- `CoffeeAndCode.csv` — dataset
- `task1_coffee_visualisation.py` — Python script
- `task1_coffeeandcode_static_heatmap.png` — final visualisation
- `task1_coffeeandcode_grouped_summary.csv` — grouped summary data
- `task1_coffeeandcode_data_cleaning_notes.txt` — cleaning notes

## How to run

Place all files in the same folder, then run:

```bash
python3 -m pip install pandas numpy matplotlib
python3 task1_coffee_visualisation.py
